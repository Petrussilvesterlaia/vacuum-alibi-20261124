Entry for the make.fun competition
[The Vacuum's Alibi: One Line, 200 Characters](https://make.fun/competitions/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7):
a program that writes one line — the funniest excuse a robot vacuum can
give for missing a spot, at most 200 characters — to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt` (one line, no trailing
newline, deterministic across runs).
